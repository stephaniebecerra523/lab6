## Lab Questions

In this lab, we learned how to apply full end one-bit adders to real life scenarios such as the light switches. 

### 1 - How might you add more than two bits together?
- To add more than two bits together, you can make a full adder.

### 2 - What is the importance of the XOR gate in an adder?
- The importance of the XOR gate in an adder is that it does binary addition of
  a single digit.

### 3 - What is the largest number a two bit adder can handle? What happens when you go over?
- The largest number a two bit adder can handle is 3 and if it goes over, the hardware won't accept it because the adder only sees the lowest two bits.
